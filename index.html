Painel de Instalação v2.1

Clique no botão abaixo para copiar o script do robô compactado para a barra de favoritos.

📌 Como adicionar no Edge:
  1. Clique no botão azul acima para copiar o código.
  2. Exiba a barra de favoritos apertando Ctrl + Shift + B.
  3. Clique com o botão direito na barra e vá em Adicionar página.
  4. Mude o nome para "Automação" e dê Ctrl + V no campo URL.
