SAP Fiori - Console Automation Tool

Clique no botão abaixo para copiar o script de automação no padrão visual SAP Fiori. Depois, cole o código na aba Console (F12) da sua tela do SAP.

Procedimento de Execução:
  1. Acione o botão acima para transferir o código para a área de transferência.
  2. Abra as Ferramentas do Desenvolvedor pressionando F12.
  3. Selecione a guia Console.
  4. Insira o código (Ctrl + V) e pressione Enter.
  5. O painel integrado surgirá alinhado no canto superior direito no padrão oficial do sistema.
