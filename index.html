Painel de Automação SAP

Clique no botão abaixo para copiar o script. Se o botão falhar, você também pode selecionar todo o texto da caixa preta e copiar manualmente (Ctrl + C).

Procedimento de Execução:
  1. Acione o botão azul acima para copiar o código (ou selecione manualmente o texto dentro da caixa preta).
  2. Abra as Ferramentas do Desenvolvedor pressionando F12.
  3. Selecione a guia Console.
  4. Insira o código (Ctrl + V) e pressione Enter.
  5. O painel integrado surgirá alinhado no canto superior direito da tela.
