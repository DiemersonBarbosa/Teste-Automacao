Painel de Automação SAP - Klabin

Esta versão quebra o atributo estático do HTML, reescrevendo o "value" oculto do SAP na raiz para garantir o endereçamento correto.

Procedimento:
  1. Salve o arquivo `index.html` com o novo código.
  2. Clique no botão azul, cole no console (F12) do SAP.
  3. Digite a faixa desejada e realize o teste definitivo. O valor fixo antigo foi quebrado!
