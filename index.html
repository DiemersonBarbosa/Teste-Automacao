Script de Automação SAP

Esta página serve para você visualizar a estrutura e manter o código salvo. O script abaixo foi desenvolvido especificamente para rodar dentro do ecossistema SAPUI5.

Nota técnica: Como este arquivo HTML não possui os elementos originais da SAP (com os IDs longos), o script exibirá um aviso de erro seguro no Console informando que o input não foi encontrado. Isso é o comportamento esperado fora do ambiente SAP.
