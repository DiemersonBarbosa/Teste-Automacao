Painel de Automação SAP

Clique no botão abaixo para copiar o código minificado pronto para ser salvo na barra de favoritos do navegador.

Como adicionar aos favoritos:
  1. Copie o código acima clicando no botão.
  2. Crie um novo favorito na barra do seu navegador (Ctrl + D / Cmd + D).
  3. Edite o favorito, altere o nome para "Automação SAP" e cole o código no campo URL (Endereço).
  4. Abra o SAP Fiori/EWM e clique no favorito criado.
