Gerador Local de Arquivos

Cole seu código ou texto abaixo, defina o nome e salve diretamente no computador.

💡 Como usar para os seus scripts:
1. Cole o código HTML ou JavaScript dentro da caixa escura acima.
2. Deixe o nome como instalador.html (ou mude se quiser salvar um .txt).
3. Clique em "Salvar Arquivo". Ele irá direto para a sua pasta de Downloads.
